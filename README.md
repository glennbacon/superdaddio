# Super Daddio

A side-scrolling platformer by Glenn Bacon: 60 levels across nine worlds, with stompable enemies,
power-ups, a jetpack, fireballs and a boss at the end of each world.

This repository holds three versions of the game:

- **The original**, written in 2012–2013 in Lua for Corona SDK, with levels built in the Gumbo
  level editor.
- **A port to JavaScript** (2026) that runs in a web browser, using [Three.js](https://threejs.org/)
  for drawing and [planck.js](https://piqnt.com/planck.js/) (Box2D) for physics.
- **A voxel remake** (2026) built on that port: the same levels, physics, sound effects and music,
  drawn in 3D. Every sprite is a voxel model made from the original pixel art.

## Play the port

You need [Node.js](https://nodejs.org/) 22 or newer.

```sh
cd web
npm install
npm run dev        # then open http://localhost:5173
```

Arrow keys or A/D run, Space jumps, X or Shift is the action button, Esc pauses. Touch controls work
too. [`web/README.md`](web/README.md) has the full controls, how the port is organised, how it was
checked against the original, and where it deliberately differs.

## Play the voxel remake

```sh
cd voxel
npm install
npm run dev        # then open http://localhost:5173
```

The controls are the same. [`voxel/README.md`](voxel/README.md) explains how the models are made
from the artwork, how the 3D scene is laid out, and what differs from the 2D port.

## What is where

| Path | Contents |
|---|---|
| `web/` | The JavaScript port, its tests, and the tool that extracts the levels from the original |
| `voxel/` | The voxel remake: the port's game code with a 3D renderer in place of the 2D one, and its tests |
| `main.lua`, `title.lua`, `selectworld.lua`, `loadlevel.lua`, `thelevel.lua`, `levelcomplete.lua`, `config.lua`, `build.settings` | The original game's source, unchanged |
| `images/`, `images2/`, `Icon*.png` | The original artwork |
| `*.wav`, `*.mp3` | The original sound effects and music |
| `ice.lua`, `Pixelated.ttf` | Other people's work that the game uses — see below |

The original is kept exactly as it was. It is the reference the port was built from, and the port's
level data is generated by running its level-building code. It was written for the Corona SDK of
2012 and does not run unmodified on today's version of that engine (Solar2D).
